# `requirements-lint.txt` would be listed twice, and the two copies could
# drift: a Dependabot bump landing in one of them leaves the union with
# two conflicting pins, and `pip install -r requirements-dev.txt` fails with
# `ResolutionImpossible`. One list, one pin, one place to bump it.
#

# (so `make secrets` needs it), because a test imports it through that
# script (so the suite needs it), and because the secrets gate runs it.
