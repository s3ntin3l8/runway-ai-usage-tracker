# Automatic macOS Claude subscription and Console connections

Goal: automatic native discovery, exact-source verification, unambiguous activation, organization picker otherwise, and native E2E proof of both paths without cookie pasting. Feature #671; close #663/#666 only after completed scope, residual native acceptance #672 and Claude Code variants #673 remain open; #526/#534/#656 remain open.

## Global Constraints
- Server never reads browser stores or Keychain. Sessions stay separate by provider and browser/profile/store source.
- No secret output, raw browser data or cookie values in APIs/logs. No OAuth refresh/write-back. No Desktop native lookup retries in this implementation. Chrome lookups authorized, reuse cached key.
- macOS first; preserve Windows/Linux and existing manual connections, explicit choices and disabled/archived accounts.
- Five-second Keychain timeout, cache success in process memory; failure suppressed until restart. Honor Desktop opt-out.
- Schema >=24 host SHA256 binding, strict PKCS7 padding, support legacy schema, explicit unsupported formats.
- Full gate before pushing; reviewed PR titled feat(sidecar): discover macOS Claude subscription and Console sessions.
