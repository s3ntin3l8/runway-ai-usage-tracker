# A floating range means a new release of a dependency lands in CI on the
# next run, with no pull request and no commit, and can turn `main` red on
# its own: the repository's own history shows that, in
# `fastapi>=0.111.0,!=0.136.3`, where a bad release was worked around with
# an exclusion instead of a pin. Dependabot is configured for pip (weekly,
# Monday, grouped), so with exact pins its pull requests are the upgrade
# path: the bump is proposed, CI validates it, and the pin moves
# deliberately.
#

# Dependabot propose it, or edit the pin and run `make install`.
